# Budgetplanner

Een persoonlijke budgetplanner die in de browser draait. Lees de CSV van je bank in (ING, Rabobank, ABN AMRO, SNS/ASN/RegioBank, bunq, Triodos, Knab) en zie je vaste lasten, wat je vrij kunt besteden, je spaardoel en een voorspelling van je saldo.

Je gegevens staan alleen in je eigen browser. Er wordt niets naar een server gestuurd.
